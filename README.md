## In the Computer Architecture course, two major projects were implemented.
# Project 1:
The first project focused on detecting the maximum clique in an undirected graph using MIPS Assembly language.
A clique is defined as a subset of vertices where every pair of vertices is directly connected. 
The goal was to identify the largest possible clique in a given graph. 
The program reads the graph as an adjacency matrix from an input text file, processes the data using low-level assembly instructions, and determines the maximum clique if it exists.
Finally, the result is written to an output file, either listing the vertices of the maximum clique or indicating that no clique was found. 
This project emphasized low-level problem solving, memory handling, and implementing complex algorithms using assembly language.

# Project 2:
The second project involved designing and implementing a multi-cycle processor using Verilog. 
The processor was structured to execute instructions across multiple stages, including instruction fetch, decode, execute, memory access, and write-back.
This project provided practical experience in understanding datapath design, control units, and how instructions are processed over clock cycles. 
It also strengthened skills in hardware description languages and simulation of digital systems.
